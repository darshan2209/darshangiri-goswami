Colophon & self-assessment

How this site is built, which processors it uses, and what is still open

Version 1.3 · 2026-11-07 · Owner: D. Goswami · Next review: 2026-12-06

I claim on the front page that I keep systems compliant, monitored and accountable. This page is where I hold my own site to that claim: the processors it relies on, the AI system I operate on it, the decisions I made and why, and the items I have not closed yet. Open items are listed because a register that only contains solved problems is not a register.

1 Build

Structure
One static index.html; no framework, no package manager, nothing to build on deploy
Hosting
GitHub Pages, deployed from the main branch
Type
Anton, Manrope and Caveat, with IBM Plex Mono for labels, as self-hosted woff2 subsets (latin + latin-ext). A typical visit loads only the latin files, 124 KB
Motion
Plain CSS and a 2D canvas, no animation or 3D library. The Motion switch in the header turns all of it off, and it starts off when your system asks for reduced motion
Background
A dotted globe on a 2D canvas with animated attack arcs. Land is Natural Earth 110m, rasterised to a 360×180 bitmask rather than a texture. The traffic it shows is simulated, and a caption beside it says so; see O-06 below
Build agents
Seven labelled agents build the page as you scroll. Every write carries an ES256-signed token from a key made in your browser with Web Crypto: one section, one kind of write, 15 seconds, with an RFC 8693-style actor chain. Every action goes into a SHA-256 hash-chained ledger that the Agent console lets you verify and tamper with. The attacker in its red-vs-blue tab is scripted: an illustration of the controls, not a test result
AI backend
Flask + gunicorn on Render, proxying the Anthropic API for LEGATE and the Fit check, so the key never reaches the browser
Agent room
Replays real runs of my agent-consult library, recorded by tools/export_agent_trace.py into assets/agent-room.js and loaded only when the section comes near the screen. No model calls and nothing simulated: the record column shows the library's own ledger entries
Cookies
None
Analytics
GoatCounter, cookieless, EU-hosted, no IP stored. No Google Analytics, no tag manager, no pixel, no heatmap
Third-party CDN
None at load time

3 AI system inventory entry

The entry I would expect to keep for any AI system in a corporate inventory, kept here for my own.

System
LEGATE, a conversational assistant (called "AI twin" until 2026-11-06), plus job-description fit analysis
My role
Deployer (Betreiber) under the EU AI Act, not the provider
Provider
Anthropic PBC, Claude Haiku 4.5 (claude-haiku-4-5-20251001)
Purpose
Answer recruiter questions from my CV; compare a pasted job description against it
Risk class
Not high-risk under Annex III. Interacts directly with natural persons, so Art. 50(1) transparency applies
Art. 50 measure
The assistant is called LEGATE, and the word AI stays next to the name: an AI tag on its button, "LEGATE · Darshan's AI" in its header, "I'm LEGATE, Darshan's AI" as its first message, and a line under the input saying it is an AI and can be wrong, with a link to the privacy notice. The Fit check keeps the full bilingual disclosure above its input. Disclosure live since 2026-07-27, chat panel shortened 2026-10-25, assistant renamed 2026-11-06; obligation applies from 2026-08-02
Inputs
Free text typed by the visitor, or spoken and turned into text by the browser's own speech recognition. Users are explicitly asked not to enter personal or confidential data
Grounding
Fixed system prompt containing my CV. The model is instructed to answer only from it and to state gaps honestly rather than invent experience
Retention
None. Inputs exist only in memory for the duration of the request
Human oversight
None in real time. Mitigated by scope limitation, output length caps, and a stated accuracy disclaimer
Known residual risks
Model may state something inaccurate about my experience; third-country transfer to the USA; free-tier availability gaps
Abuse controls
CORS restricted to this origin; 20 requests/IP/minute; 2,000 characters per message; 12-turn history cap
Review
2026-12-06, or on any change of model, prompt or hosting region

5 Open items

Not yet resolved, listed with what each would take to close.

RefItemAssessmentStatus
O-01 No Impressum published § 5 DDG exempts only services that are exclusively personal or family-purpose, and this exemption is read narrowly. A job-seeking portfolio is arguably self-marketing and therefore in scope. Publishing one requires a ladungsfähige Anschrift, a real postal address, permanently public. Deferred deliberately while I decide which address to use, not overlooked Open
O-02 AI relay runs in a US region The Render service has no region pinned and therefore defaults to the USA. Transfer is covered by SCCs, but an EU region (Frankfurt) would reduce the transfer entirely. Cost: a redeploy Planned
O-03 Processor agreements not yet countersigned Render and Anthropic both offer Art. 28 DPAs. Until I have accepted both in writing, the transfer basis stated in the register is the standard offering rather than an executed agreement. Stated plainly rather than implied Open
O-04 No light mode The redesign added print stylesheets, so a printed or PDF-exported page now comes out dark on white, which matters in a market where applications are assembled as PDFs. Reading on screen is still dark only Planned
O-06 Background globe animates simulated attack traffic The arcs are generated, not observed. Origin and target coordinates are real cities, but no detection, log or feed sits behind them, it is an illustration, and the page says so permanently in the caption beside the canvas rather than leaving a viewer to assume it is live telemetry. The honest upgrade is to replace it with real data from my own Wazuh honeypot, with a collection window and an event count stated alongside it Planned
O-05 Published GRC artifacts carry no provenance header The risk register, SoA excerpt and access review procedure are self-authored on synthetic scenarios with no employer or client data. That should be stated on each artifact, because an unlabelled realistic register invites the question of where it came from Open
